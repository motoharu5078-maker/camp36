# CAMP 36 — 12.23 計量日

12月23日を「試合の計量日」に見立てた、36日間のトレーニングキャンプ用スマホWebアプリ。
期間は **2026/11/18（水）= DAY 1 〜 12/23（水）= DAY 36**。11/17 は DAY 0（初回計測日）。

- 毎日やることが一目で分かる（TODAY）
- 記録が10秒で終わる（体重・睡眠・歩数・むくみ・肌）
- 変化が目で見える（顔写真の比較・タイムラプス・体重グラフ）

## 公開URL

**<https://motoharu5078-maker.github.io/camp36/>**

GitHub Pages（main ブランチ / ルート）で公開している。HTTPS なので、カメラのライブ撮影も使える。

### 更新のしかた

ファイルを直したら、このフォルダでコミットして push する。1〜2分で公開URLに反映される。

```bash
git add -A && git commit -m "update" && git push
```

アプリ本体（`index.html`・`css/`・`js/`）を変えたときは、`sw.js` の `VERSION` も1つ上げる（スマホ側の古いキャッシュが入れ替わる）。

## iPhone でホーム画面に追加する

1. **Safari** で <https://motoharu5078-maker.github.io/camp36/> を開く（Chrome ではなく Safari）。
2. 画面下の **共有ボタン**（四角から矢印が出ているアイコン）をタップ。
3. **「ホーム画面に追加」** をタップ → 右上の「追加」。
4. ホーム画面の **CAMP 36** アイコンから開く。アドレスバーのない全画面アプリとして起動する。一度開けば、電波がなくても起動できる。

初回に顔写真を撮るとき、カメラの許可を聞かれるので「許可」を選ぶ。

## 使い方

| タブ | やること |
|---|---|
| **TODAY** | カウントダウン、今日のチェックリスト（朝・日中・ジム・夜）、数値記録、今日のスコア、むくみ予報。右上のアイコンが設定。 |
| **FACE** | 顔写真（正面＋横顔）。輪郭ガイドと、前回の写真を30%で重ねるゴースト表示つき。比較スライダー、タイムラプス、カレンダー一覧。 |
| **GYM** | chocoZAP のA日／B日メニュー。前回の重量×回数と次回の提案、1タップ入力、セット間の休憩タイマー。 |
| **ROADMAP** | 36日の全体図、体重グラフ（点＝毎日、線＝7日平均）、火曜夜の週次レビュー、むくみの答え合わせ。 |
| **BOOK** | 顔痩せ／減量／筋トレ／肌／仕上げ／やらないこと、の知識カード。 |

- **毎晩の顔痩せ動画**：TODAY の「夜」から開く。7:00 のタイマーが終わると完了を付けられる。メモ欄あり。
- **未来の自分への手紙**：DAY 0 に書いて封をすると、12/23 まで開けられない。
- **通知**：設定 →「カレンダー用ファイル（.ics）を書き出す」→ 開いて「すべてを追加」。iPhone のカレンダーが通知してくれる。
- **12/23**：TODAY に「36日のまとめ」と「手紙を開封する」が出る。

## データについて

**データはこの端末の中だけ。**

- 設定・チェック・数値記録 → ブラウザの `localStorage`（キーは `camp36:` で始まる）
- 顔写真 → `IndexedDB`（長辺1080px・JPEG に縮小して保存）
- **顔写真をサーバーに送ることは一切ない。** アカウントも、アクセス解析も、外部への送信もない（外部と通信するのは YouTube の動画埋め込みだけ）。
- ブラウザのデータを消すと全部消える。設定 →「全データを書き出す」で JSON（写真込み）を保存しておけば、「バックアップを読み込む」で戻せる。機種変更のときも同じ。

## 日付を差し替えて確認する

URL の末尾に `?date=2026-12-23` を付けると、その日の画面になる（`#/today` より前に書く）。

```
https://motoharu5078-maker.github.io/camp36/?date=2026-12-23#/today
```

`&hour=21` で時刻（日本時間）、`&timer=5` で動画タイマーを5秒にできる。日付はすべて Asia/Tokyo 基準。

## 手元で動かす

ビルドは不要。静的ファイルをそのまま配信するだけ。このフォルダで次を実行する。

```bash
python3 -m http.server 8136
```

<http://localhost:8136> を開く（`npx serve` でも同じ）。localhost ではカメラのライブ撮影も Service Worker も動く。

## 構成

```
index.html / manifest.webmanifest / sw.js
css/      fonts.css（同梱フォント） app.css
js/       app.js（ルーティング） dates.js（日本時間） store.js（localStorage） photos.js（IndexedDB）
          data.js（フェーズ・メニュー・BOOK） calc.js（目標・スコア・週次レビュー） io.js（.ics・バックアップ）
          views/  today / face / gym / roadmap / book / video / settings / setup / letter / final
fonts/    Anton・Zen Kaku Gothic New（700/900）・IBM Plex Mono（SIL Open Font License。ライセンス文を同梱）
icons/    icon.svg と、そこから作った PNG（192 / 512 / apple-touch）
tools/    フォントのサブセット化、アイコン生成、動作テスト、BOOK の字数チェック
screenshots/  幅 320 / 375 / 390 / 430px の全画面（写真はテスト用に描いた絵）
```

## テスト

```bash
NODE_PATH=<playwright-core を入れた node_modules> node tools/test.cjs
```

ヘッドレス Chrome で、初回設定の通し操作、DAY 0〜36 のフェーズ・チェックリスト・ジムメニュー、撮影（ライブ／フォールバック）、比較、タイムラプス、動画タイマー、ジムの提案と休憩タイマー、週次レビュー、.ics、バックアップの往復、オフライン起動を確認し、4つの幅で横スクロール・タップ領域（44px）・入力欄の文字サイズ（16px）を検査して `screenshots/` に保存する。

## 注意

体調に異変があれば中止して医師に相談。断食・水抜き・サプリの過剰摂取など、極端な方法はこのアプリには入れていない。
